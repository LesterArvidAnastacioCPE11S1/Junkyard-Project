# Junkyard-Project

An NLP-powered recycling management system designed to support junkshops in processing customer inquiries, identifying recyclable materials, and improving recycling-related operations.

# Overview

This Junkyard-Project or RecyclablePricingAssistant is a Python-based project that integrates Natural Language Processing (NLP) into a recycling management system to help modernize how junkshops handle recyclable material inquiries and related operational tasks.

The system focuses on understanding customer messages written in English, Filipino, and Taglish, allowing it to identify recyclable materials from informal descriptions rather than requiring users to follow rigid input formats. Its material classification component is being developed using a custom dataset containing single-material and multiple-material descriptions.

Beyond material identification, the project aims to support additional junkshop operations, including recyclable price inquiry classification, next-day buying price forecasting based on historical records, pickup request organization, bulk-rate negotiation identification, and recycling analytics.

The project is intended to explore how NLP and data-driven methods can help make recycling transactions more organized, accessible, and efficient, particularly for junkshops that still rely on manual processes.

# Core Objectives

- Material Identification: Identify recyclable material categories from natural-language customer messages, including descriptions containing multiple materials.
- Message Classification: Distinguish between different types of customer inquiries, such as price inquiries, pickup requests, and bulk-rate negotiations.
- Price Forecasting: Explore forecasting next-day recyclable buying prices using historical price records.
- Pickup Organization: Support the organization of pickup requests based on operational factors such as driver availability.
- Recycling Analytics: Organize recycling-related information to support monitoring and data-driven decision-making.

# Technologies

Python
Natural Language Processing (NLP)
Machine Learning

# Current Development Status

The project is being developed incrementally, beginning with the material classification component and the preparation and expansion of its multilingual dataset. Additional system components will be developed as the project progresses.

RecyclablePricingAssistant is a work in progress, with planned features subject to implementation, testing, and evaluation.
